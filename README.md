### 🔳 **Modern / Clean Styles**

| Style               | Vibe                | Description                                                   |
| ------------------- | ------------------- | ------------------------------------------------------------- |
| **Minimalist**      | Zen, elegant        | Lots of white space, simple layout, few colors.               |
| **Flat Design**     | Simple, clean       | No shadows or 3D, just flat colors and icons.                 |
| **Material Design** | Structured, tactile | Google's design system with depth, movement, and bold colors. |
| **Neumorphism**     | Soft, futuristic    | Elements look pressed into the screen, soft shadows.          |
| **Glassmorphism**   | Sleek, airy         | Translucent, frosted glass effects with blur.                 |
| **Claymorphism**    | Playful, rounded    | Soft 3D elements with big shadows and vivid colors.           |
| **Metro UI**        | Techy, grid-based   | Inspired by Windows UI, strong focus on tiles and motion.     |

| Style              | Vibe               | Description                                        |
| ------------------ | ------------------ | -------------------------------------------------- |
| **Brutalism**      | Raw, rebellious    | Anti-design, rough layouts, clashing colors.       |

| **Dark Mode**      | Cool, modern       | Everything in black or dark gray.                  |
| **Cyberpunk**      | Futuristic, neon   | Glitch effects, bold type, purples/pinks on black. |
| **Neo-noir**       | Moody, cinematic   | Dark themes with elegant lighting and gradients.   |
| **Gothic Web**     | Mystical, romantic | Ornate fonts, black/red palettes, medieval motifs. |
